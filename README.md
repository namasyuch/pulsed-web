# Pulse Web 

Pulse Web is a simple website that shows NASA's Astronomy Picture of the Day.

## What it does

* Gets the latest picture from NASA
* Shows the picture title and date
* Shows the image description
* Updates when a new APOD is available

## Built with

* HTML
* CSS
* JavaScript
* Vite
* NASA APOD API

## Live Website

https://namasyuch.github.io/pulsed-web/

## How I made it

I built the page with Vite and JavaScript. The website uses NASA's APOD API to get the picture and its information.
